# AGV/AMR 运营平台：阿里云 / 腾讯云 / 自建服务器 对比表


| 对比维度 | 阿里云 | 腾讯云 | 自建服务器（机房/本地） |
|---|---|---|---|
| **适合场景** | 商用交付、多工厂、跨区域、追求稳定 | 初创内测、预算有限、小规模项目 | 工厂内网禁公网、等保合规、数据不出厂 |
| **初始成本** | 低（几百～2k/年） | 极低（新用户特惠） | 极高（服务器+机房+UPS+网络） |
| **运维难度** | 极低（云厂商托管硬件/网络） | 极低（云厂商托管硬件/网络） | 极高（需专职运维，硬件/网络/故障全自己管） |
| **部署速度** | 快（小时级上线） | 最快（小时级上线） | 慢（数周～数月） |
| **稳定性** | 99.975%，工业IoT最优 | 99.975%，稳定可靠 | 看环境，易受断电/硬盘/网络影响 |
| **网络延迟** | 低，BGP全网优质 | 低，国内流畅 | 内网极低；公网不稳定 |
| **安全能力** | 强（DDoS、防火墙、加密） | 强（DDoS、防火墙、加密） | 自主把控，但需额外投入安全设备 |
| **扩展能力** | 弹性扩容，分钟级升级 | 弹性扩容，分钟级升级 | 差，升级要换硬件、周期长 |
| **EMQX适配** | 完美支持，文档全 | 完美支持，性价比高 | 支持，但网络与可靠性自己保障 |
| **公网访问** | 天然支持，跨区统一运营 | 天然支持，跨区统一运营 | 需公网IP/专线，复杂且贵 |
| **推荐程度** | ⭐⭐⭐⭐⭐（首选） | ⭐⭐⭐⭐（性价比首选） | ⭐⭐（仅特殊合规场景） |

---

# 一句话选型建议
- 要**商用、稳定、少出事** → 选 **阿里云**
- 要**省钱、先做试运行** → 选 **腾讯云**
- 工厂**必须内网、不许上云** → 才选 **自建**
