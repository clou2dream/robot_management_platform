# 模块一：机器人接入同步 — 详细设计

> 版本：v2.0 | 日期：2026-05-14  
> 状态：原“机器人授权/激活”能力已从本平台移出，改由外部授权平台负责

---

## 一、调整说明

机器人首次授权、APP ID 管理、API Key / API Secret 下发、EMQX 认证回调、凭证吊销等能力，暂不在当前机器人运营管理平台中建设，后续统一放到另一个网页平台（下文称“外部授权平台”）完成。

当前平台只负责：

- 同步或读取外部授权平台中已经完成授权的机器人
- 展示机器人基础信息、在线状态、巡检数据和任务数据
- 对运营人员做机器人访问范围授权（`operator_robot_access`）
- 对已同步机器人下发任务、查看告警、查看历史状态

当前平台不负责：

- 创建、修改、吊销 APP ID
- 机器人首次上线自动注册和激活
- 生成、展示、轮换、删除机器人 API Key / API Secret
- EMQX HTTP 认证回调 `/internal/mqtt/auth`
- activation Topic 凭证下发
- 机器人凭证泄露处理

## 三、机器人数据来源

当前平台需要从外部授权平台获得已授权机器人清单。对接方式按实施条件选择其一：

| 方式 | 说明 | 适用阶段 |
|------|------|----------|
| 数据库视图 / 同库只读表 | 外部授权平台写入机器人表，本平台只读 | 内部系统同库部署时优先 |
| HTTP API 同步 | 本平台定时调用外部授权平台 API 拉取机器人清单 | 跨系统部署时使用 |
| 消息事件同步 | 外部授权平台在机器人授权/吊销后发布事件，本平台消费更新 | 后续扩展 |
| 手动导入 | MVP 早期用 CSV/SQL 导入已授权机器人 | 临时方案 |

MVP 阶段建议先采用“HTTP API 同步”或“手动导入”，避免把外部平台未完成的部分阻塞住巡检和任务功能。

## 四、同步字段

当前平台只保存运维所需字段，不保存机器人密钥。

```sql
CREATE TABLE robots (
    id                  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id           UUID NOT NULL REFERENCES tenants(id),
    external_robot_id   TEXT NOT NULL,              -- 外部授权平台的机器人 ID
    serial_number       TEXT NOT NULL,
    manufacturer        TEXT,
    app_id              TEXT,                       -- 机器人业务身份标识，可从外部平台同步；不用于本平台 MQTT 认证
    status              TEXT NOT NULL DEFAULT 'active'
                        CHECK (status IN ('active','revoked','disabled')),
    synced_at           TIMESTAMPTZ NOT NULL DEFAULT now(),
    created_at          TIMESTAMPTZ NOT NULL DEFAULT now(),
    UNIQUE (tenant_id, external_robot_id),
    UNIQUE (tenant_id, serial_number)
);
```

字段说明：

| 字段 | 说明 |
|------|------|
| `external_robot_id` | 外部授权平台中的机器人唯一 ID |
| `serial_number` | 机器人 SN，用于匹配 VDA5050 Topic |
| `manufacturer` | 厂商标识，用于构造 Topic |
| `app_id` | 外部平台生成的机器人业务标识，仅用于展示和排查 |
| `status` | 外部平台同步来的机器人状态，当前平台不主动吊销凭证 |
| `synced_at` | 最近一次同步时间 |

## 五、同步流程

### 5.1 定时全量同步

```
定时任务触发
    → 调用外部授权平台机器人列表 API
    → 按 external_robot_id / serial_number 匹配本地 robots
    → 新机器人：插入 robots
    → 已存在机器人：更新 manufacturer、app_id、status、synced_at
    → 外部平台已吊销/禁用：本地 status 更新为 revoked/disabled
```

### 5.2 手动同步

后台保留一个 admin 可用的“同步机器人”操作，用于 MVP 阶段快速拉取最新机器人清单。

```
admin 点击同步
    → POST /api/robots/sync
    → 后端调用外部授权平台
    → 返回新增、更新、禁用数量
```

### 5.3 不处理凭证

同步流程只处理机器人元数据，不同步、不展示、不缓存 API Secret。当前平台也不提供凭证创建、删除、重置能力。

## 六、接口设计

| 方法 | 路径 | 说明 | 权限 |
|------|------|------|------|
| GET | `/api/robots` | 查询已同步机器人列表 | admin / operator / viewer |
| GET | `/api/robots/{id}` | 查询机器人详情 | admin 或有访问权的 operator/viewer |
| POST | `/api/robots/sync` | 从外部授权平台同步机器人 | admin |
| GET | `/api/robots/{id}/sync-status` | 查看机器人最近同步信息 | admin / operator / viewer |

> 原 `GET /api/app-ids`、`POST /api/app-ids`、`GET /api/robots/{id}/credentials` 等 APP ID / API 凭证接口不在当前平台实现。

## 八、已确认决策

| 事项 | 决策 |
|------|------|
| 机器人授权/激活 | 移到外部授权平台 |
