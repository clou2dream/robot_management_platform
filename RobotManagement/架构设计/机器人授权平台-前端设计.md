# 机器人授权平台 — 前端设计

> 版本：v1.0 | 日期：2026-05-15  
> 定位：独立于机器人运营管理平台的授权管理前端，负责机器人首次授权、APP ID、API 凭证与激活记录管理。

---

## 一、设计边界

机器人授权平台负责“机器人能否接入 MQTT 通道”的前置管理；机器人运营管理平台只消费已授权机器人，用于巡检、任务、告警和人员访问授权。

| 能力 | 授权平台前端 | 运营管理平台前端 |
|------|--------------|------------------|
| APP ID 管理 | 负责 | 不展示 |
| 接入配额管理 | 负责 | 不展示 |
| 机器人首次激活记录 | 负责 | 不展示 |
| API Key / API Secret 管理 | 负责 | 不展示 |
| 凭证吊销 / 重发 | 负责 | 不展示 |
| 已授权机器人同步状态 | 可展示 | 只展示同步结果 |
| 巡检 / 任务 / 告警 | 不负责 | 负责 |


## 三、核心页面

### 3.1 授权工作台

展示授权平台的整体状态：

| 指标 | 说明 |
|------|------|
| APP ID 数量 | 当前租户可用 APP ID |
| 已授权机器人 | status = active 的机器人数量 |
| 近 24 小时激活失败 | 失败激活记录数量 |
| 凭证风险 | 过期、吊销、异常重试等风险提示 |

快捷操作：

- 创建 APP ID
- 查看激活失败记录
- 查看凭证风险
- 打开接入说明

### 3.2 APP ID 管理

用于管理机器人首次接入时使用的租户级标识。

表格字段：

| 字段 | 说明 |
|------|------|
| 名称 | 例如上海工厂、北京仓库 |
| APP ID | 首次接入使用的租户标识，支持复制 |
| 配额 | 允许激活的机器人数量 |
| 已使用 | 当前已激活或待激活机器人数量 |
| 使用率 | 进度条展示，超过 80% 警告 |
| 状态 | active / revoked |
| 创建时间 | created_at |
| 操作 | 修改配额 / 吊销 / 查看激活记录 |

交互要求：

- 创建 APP ID 使用抽屉表单。
- APP ID 只展示一次完整值，后续可复制但不展示敏感扩展字段。
- 吊销 APP ID 需要二次确认，并说明“只影响新的首次接入，不自动吊销已激活机器人”。

### 3.3 授权机器人列表

展示授权平台中的机器人接入状态。

表格字段：

| 字段 | 说明 |
|------|------|
| SN | 机器人序列号 |
| 厂商 | manufacturer |
| APP ID | 首次接入使用的 APP ID |
| 状态 | pending / active / revoked |
| 最近连接 | last_seen_at |
| 激活时间 | activated_at |
| 凭证数量 | 当前有效 API Key 数量 |
| 操作 | 详情 / 吊销 / 重发凭证 |

### 3.4 激活记录

用于排查机器人从 APP ID + SN 到 API 凭证激活的全过程。

状态时间线：

```
APP ID + SN 认证通过
    → 创建 pending 机器人记录
    → 机器人 connection ONLINE
    → 生成 API Key / API Secret
    → MQTT activation Topic 下发凭证
    → 机器人使用 API Key / Secret 重连
    → 激活完成
```

失败原因需要清晰展示：

- APP ID 不存在或已吊销
- 配额已满
- SN 重复
- MQTT activation 消息下发失败
- API Secret 校验失败
- 机器人长时间未使用新凭证重连

### 3.5 API 凭证管理

采用“Key 可见、Secret 仅创建时展示一次”的交互。

规则：

- API Secret 只在创建或重发成功后展示一次。
- 页面不允许重新查看 Secret。
- 删除或吊销凭证需要二次确认。
- 凭证权限以 Tag 展示，例如 `state:read`、`order:write`、`instantAction:write`。

### 3.6 审计日志

记录关键授权操作：

- 创建 / 修改 / 吊销 APP ID
- 机器人首次激活
- 吊销机器人
- 创建 / 删除 / 重发凭证
- 登录失败、账号锁定等安全事件

## 四、权限设计

| 角色 | 权限 |
|------|------|
| admin | 管理 APP ID、配额、机器人凭证、审计日志 |
| operator | 查看授权机器人、查看激活记录、发起凭证重发申请 |
| viewer | 只读查看授权状态和激活记录 |

高风险操作仅 admin 可执行，包括吊销 APP ID、吊销机器人、删除凭证。

---

## 五、与运营管理平台的衔接

授权平台需要提供“已授权机器人清单”给运营管理平台同步。前端只展示同步状态，不直接调用运营平台数据库。

推荐在机器人详情页展示：

- 是否已同步到运营管理平台
- 最近同步时间
- 同步失败原因
- 手动重新推送事件按钮

---

## 六、MVP 范围

纳入 MVP：

- 登录
- APP ID 管理
- 授权机器人列表
- 激活记录
- API 凭证创建、吊销、重发
- 审计日志基础查询

暂缓：

- 多级审批
- 批量导入机器人
- 凭证轮换策略自动化
- 高级统计报表
